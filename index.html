Scope of this tool. Implements Section 7 (Design Traffic / ESA calculation); the Section 11.8.3 pavement catalogue for lightly-trafficked granular pavements with thin bituminous surfacing (design traffic ≤ 3×106 ESA); the Section 8.3.1 empirical design chart (Figure 8.4) for granular pavements with thin bituminous surfacing, covering the wider 105–108 ESA range — per §8.2.7 this chart gives a total granular thickness equivalent to the full mechanistic-empirical procedure (using a top granular modulus of 350 MPa), so it is used here as the practical, closed-form stand-in for that procedure; and the Section 9 minimum-requirement tables for rigid (concrete) pavements. It does not implement the fatigue/erosion nomograph procedure of Section 9.4 for heavily-trafficked rigid pavements — that requires specialist software and a qualified pavement engineer. Every figure in Tabs 1–3 and 5 is transcribed from the source PDF and cited by clause; verify against the original document for final design submissions. Tab 4 (Mechanistic-Empirical) is a separate, experimental addition: since §8.2 itself delegates the layered-elastic strain calculation to external software (AustPADS/CIRCLY) rather than providing the method, Tab 4 is an independently-built implementation of that general theory — not part of the official MPWT specification, unvalidated against MPWT-recognised software, and not to be used for a submission without an engineer's independent check. See the warning banner on that tab for details. Tab 5 (Overlay Design) implements Section 12.3, the empirical design of granular overlays for rehabilitating granular pavements (deflection testing, seasonal/device adjustment, characteristic deflection, and overlay thickness — fully closed-form, valid to 108 ESA). Section 12.4's mechanistic-empirical strengthening design (for pavements with asphalt/cemented layers) requires FWD deflection-bowl back-calculation software this tool does not implement; that tab explains the gap and how to combine externally back-calculated moduli with the Tab 4 solver.

⚠️ Experimental — Unvalidated Against Reference Software

D3 102-2024 §8.2 does not itself provide the layered-elastic strain-calculation method — it explicitly requires "computer programs such as AustPADS" (§8.2, list of significant features) capable of modelling a multi-layer elastic pavement. This tab is an independent implementation of that general layered-elastic (Burmister-type, n-layer axisymmetric elastic) theory, derived and coded from first-principles continuum mechanics — it is not part of the official MPWT specification and MPWT has not reviewed or endorsed it.

What has been checked: the solver's stresses/strains match the closed-form Boussinesq single-layer solution to machine precision, and match a published 3-layer benchmark (Jones 1962 / cross-checked by Wang, Roesler & Guo 2011) to 4–5 significant figures. What has NOT been checked: there is no access to AustPADS, CIRCLY, or any MPWT-approved software in this environment to cross-validate real project inputs.

Scope limitation: this module evaluates the critical strain directly beneath the centre of a single circular wheel load only (on-axis). It does not implement multi-wheel (dual-tyre) superposition or the "between tyres" check shown in Figure 8.2 / Table 8.2 of the Specification — for many pavements the single-wheel, under-load case shown here is not the only location that needs checking.

Do not use these results for an MPWT submission or construction decision without independent verification by a qualified pavement engineer using MPWT-recognised software (e.g. AustPADS/CIRCLY).

Overlay Design — Rehabilitation of Existing Pavements

D3 102-2024 Section 12 — Overlays for Flexible Pavements.

Section 12 covers two distinct routes, depending on whether the existing pavement contains asphalt and/or cemented material:

  • §12.3 — Empirical design of granular overlays (implemented below): for existing pavements that are granular only (no asphalt/cemented layers), valid up to 108 ESA. Fully closed-form — deflection testing (Benkelman Beam or FWD) drives the required overlay thickness directly.
  • §12.4 — Mechanistic-empirical procedure (MEP) for strengthening treatments: required whenever the existing pavement contains asphalt and/or cemented material (asphalt overlays/inlays, major patching, stabilisation). This route requires back-calculating the existing layer/subgrade moduli from measured FWD deflection bowls — a specialist, iterative numerical process (§12.4.3–12.4.9) that needs dedicated back-calculation software (e.g. EVERCALC, MODULUS, or a CIRCLY back-calculation module). This tool does not implement back-calculation — see the guidance card at the bottom of this tab for how to combine externally back-calculated moduli with the Tab 4 mechanistic-empirical solver.
Confirm which route applies before proceeding: if the existing pavement includes any asphalt or cemented/stabilised layer, the §12.3 granular-overlay calculator below does not apply to it (§12.3.3) — go to the §12.4 guidance card instead.

On the overlay-thickness formula: D3 102-2024 provides Figure 12.3 as a design chart, not a closed-form equation. The Specification states the chart "is based on available field data that indicates a 6% reduction in deflection for each 25 mm of granular overlay thickness" (§12.3.3). This tool reconstructs that stated relationship as t = 25 × ln(CDfactored / Ddesign) / ln(0.94) (mm) — this closed-form expression is this tool's own derivation from the stated field-data basis, not a value transcribed directly from the Specification. Cross-check against the actual Figure 12.3 chart in the source PDF before using for a submission.
Assumes a thin (< 40 mm) bituminous surfacing after the overlay (§12.3). If the existing pavement has a thin bituminous seal within 300 mm of the finished surface level, consider removing or breaking it in wetter climates so water is not trapped in the overlay (§12.3.3).

§12.4 — Mechanistic-Empirical Strengthening (Asphalt/Cemented Pavements)

For existing pavements containing asphalt and/or cemented material — not computed by this tool.

§12.4's MEP mirrors the new-pavement mechanistic-empirical procedure already implemented in Tab 4 (§8.2), except the layer moduli for the existing pavement and subgrade must first be estimated from FWD deflection-bowl back-calculation (§12.4.4) — a trial-and-error numerical fitting process, typically run in dedicated software, that iterates layer moduli until the predicted deflection bowl matches the measured one. This tool has no such back-calculation engine, so §12.4.1–12.4.9 (homogeneous sub-sectioning for back-calculation, seed-modulus selection, temperature/traffic-damage modulus reduction factors — Equations 12.4–12.16 — and presumptive cracked-material properties, Table 12.7) are out of scope here.

How to bridge to Tab 4: once existing layer/subgrade design moduli have been back-calculated and adjusted (temperature, seasonal moisture, and future fatigue-damage reduction per §12.4.5–12.4.8) using appropriate specialist software, they can be entered directly as the bottom layers of a Tab 4 layer stack, with the proposed new overlay layer(s) added on top — Tab 4's solver already supports an arbitrary n-layer stack and evaluates critical strains against the same Section 5/6 fatigue criteria this rehabilitation design also uses. Two points from §12.4.1 to carry across: existing bound (asphalt/cemented) layers are normally assumed to have negligible remaining fatigue life, so only the fatigue life of the new materials is usually checked; and reflective cracking risk from cracked material below is a real concern — new-pavement design uses 175 mm of sound asphalt cover over cemented/RCC/LMC material as its benchmark for that risk.

Engage a qualified pavement engineer with FWD back-calculation software for any §12.4 strengthening design — do not substitute the §12.3 granular-overlay calculator above for pavements containing asphalt or cemented material.
